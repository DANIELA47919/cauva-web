# CAUVA — sitio web listo para GitHub Pages

## Para actualizar tu sitio

1. Descomprime este archivo.
2. Entra al repositorio `cauva-web` en GitHub.
3. Elimina o reemplaza el `index.html` anterior.
4. Sube **todo el contenido de esta carpeta**, manteniendo:
   - `index.html`
   - `styles.css`
   - `script.js`
   - carpeta `assets`
5. Confirma con **Commit changes**.
6. Espera entre 1 y 5 minutos y abre https://cauva.cl

## Importante

- No modifiques la configuración DNS.
- El dominio personalizado debe seguir siendo `cauva.cl` en Settings → Pages.
- Cuando GitHub lo permita, activa **Enforce HTTPS / Aplicar HTTPS**.
