# CAUVA Web completa lista para subir

## Publicación en GitHub Pages
1. Descomprime este ZIP.
2. Entra al repositorio `DANIELA47919/cauva-web`.
3. Sube todo el contenido de esta carpeta.
4. Reemplaza los archivos anteriores.
5. Confirma con `Commit changes`.
6. Espera entre 1 y 5 minutos.
7. Abre https://cauva.cl

## Archivos incluidos
- index.html
- styles.css
- script.js
- CNAME
- .nojekyll
- assets/img con todas las imágenes necesarias

No debes crear carpetas adicionales ni cambiar los nombres de las imágenes.
No modifiques nuevamente el DNS de GoDaddy.
